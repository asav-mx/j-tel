# Marco Limpio JTEL — Pieza 1

Dominio y leyes intocables. Ver especificación completa en el plan de construcción.

## Leyes intocables

1. El servicio = ruta × turno × fecha; la unidad es evidencia.
2. La verdad se calcula una vez (`compliance_facts`) y todos leen el mismo hecho.
3. Esperado y observado siempre en campos separados.
4. Sin evidencia ≠ incumplimiento → `pendiente_evidencia`.
5. GPS es dispositivo intercambiable; unidad tiene identidad estable.
6. Multi-cuenta desde el cimiento.
7. Verificación post-deadline, no en pantalla.
